# AskMiao (AI ChatBot)

[Traditional Chinese](llms.txt) | [English](llms_en.txt)

> An enterprise-grade intelligent knowledge-base conversational system powered by Contextual Hybrid RAG (Retrieval-Augmented Generation) and Agentic Autonomous Research, extensible with agent tools imported from OpenAPI specs and MCP servers.

## Core File Map & System Architecture

### Backend entry point and infrastructure
- [backend/main.py](backend/main.py): FastAPI entry point, logging setup, and mounting of the seven routers (auth, chat, admin, documents, api-tools, mcp, tags)
- [backend/app/middleware.py](backend/app/middleware.py): SecurityHeaders, RateLimit, and CORS middleware registration
- [backend/app/core/lifespan.py](backend/app/core/lifespan.py): Startup flow (create tables, RAG singleton, uploads watcher, index rebuilder)
- [backend/app/core/config.py](backend/app/core/config.py): Single source of truth for all environment variables and defaults (pydantic-settings)
- [backend/app/models/__init__.py](backend/app/models/__init__.py): SQLAlchemy tables (users, conversations, messages, documents, custom_api_tools, mcp_servers) and Pydantic request models

### Agentic RAG core
- [backend/app/rag/contextual_rag.py](backend/app/rag/contextual_rag.py): HybridContextualRAG facade module
- [backend/app/rag/pipeline.py](backend/app/rag/pipeline.py): RAG pipeline, context assembly, and agent integration
- [backend/app/rag/agent.py](backend/app/rag/agent.py): ReAct autonomous ResearchAgent (multi-turn tool calling, streaming events, research trace)
- [backend/app/rag/tools.py](backend/app/rag/tools.py): ResearchToolRegistry aggregating built-in tools (search_knowledge_base, filter_and_count_records, web_search, web_fetch), custom API tools, and MCP tools
- [backend/app/rag/indices/vector_store.py](backend/app/rag/indices/vector_store.py): FAISS dense vector indexing and similarity search
- [backend/app/rag/indices/bm25_store.py](backend/app/rag/indices/bm25_store.py): Whoosh BM25 keyword search index
- [backend/app/rag/retrievers/hybrid.py](backend/app/rag/retrievers/hybrid.py): Hybrid search combiner and Cross-Encoder re-ranker
- [backend/app/core/llm_client.py](backend/app/core/llm_client.py): Unified LLM client (Azure OpenAI v1 / OpenAI / Claude / Gemini / Ollama)

### Tool extension (OpenAPI and MCP)
- [backend/app/api/api_tools.py](backend/app/api/api_tools.py): Custom API tool endpoints (parse-spec, import, CRUD, toggle, test) and the generic HTTP executor execute_http_api_tool
- [backend/app/services/openapi_parser.py](backend/app/services/openapi_parser.py): OpenAPI 2.0 / 3.0 / 3.1 spec parsing and $ref resolution

## Key Architectural Invariants & Concepts

1. **Agentic RAG Pipeline**:
   - ReAct pattern where the model decides to call internal knowledge search, structured counting, live web search, web fetch, or any registered custom API / MCP tool.
   - `POST /api/chat/send` streams SSE events (start, step_start, step_end, token, sources, done, error); every answer yields a structured `research_trace` and clickable `sources_detail`.
2. **Reasoning Effort Multi-Tier Selection**:
   - Supports `none`, `low`, `medium`, `high`, and `xhigh`, forwarded to Azure OpenAI v1 / OpenAI reasoning models with Microsoft Foundry tool-call compatibility rules.
3. **Hybrid Retrieval**:
   - FAISS dense vectors (`BAAI/bge-small-zh-v1.5`) and Whoosh BM25 (Jieba segmentation) fused by `HYBRID_ALPHA`, then re-ranked by a Cross-Encoder (`BAAI/bge-reranker-base`); all parameters are defined in `config.py`.
4. **Tool Extension (OpenAPI import and MCP)**:
   - Custom API tools use `custom_api_tools.name` as the function name; MCP tools are named `mcp_{server}_{tool}`; both are aggregated dynamically by `ResearchToolRegistry`, and `GET /api/chat/tools` exposes the currently enabled set.
5. **Outbound SSRF Protection**:
   - Every URL supplied by a user or the model (web_fetch, OpenAPI spec loading, custom API execution) MUST pass `ssrf_protection.validate_url_ssrf` / `safe_fetch_text`, which rejects private, loopback, and link-local addresses.
6. **System-Wide Security Redaction**:
   - Recursive object masking and regex-based string redaction. Passwords, tokens, and Authorization headers MUST appear as `[REDACTED]` in logs.
7. **Modern Lightweight Stack**:
   - SQLite by default on the backend (PostgreSQL optional via `backend/docker-compose.yml`, host port 7690); the token blacklist is a single-process in-memory implementation. Frontend built on React 19 + TypeScript + Vite 8 + Bun.
